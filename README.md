# Russian Car Shredder

Заготовка онлайн-игры на Unity по типу режима SUMO из GTA Online: игроки на машинах выталкивают друг друга с арены.

## Что реализовано

- **Управление автомобилем.** Скрипт подстраивается под конкретную машину через `CarConfig` (ScriptableObject): подвеска, скорость, разгон, поворот, торможение. Новая машина добавляется без правки кода.
- **Онлайн на Photon PUN 2.** Лобби, создание комнат (в том числе с паролем), список комнат, синхронизация игроков.
- Поддержка клавиатуры и мобильного джойстика.

## Запуск

1. Открыть проект в Unity 6000.2.6f2.
2. Указать свой Photon App ID в настройках PUN.
3. Запустить сцену `Assets/Scenes/Menu.unity`.

## Стек

Unity 6 · HDRP · Photon PUN 2 · C#
